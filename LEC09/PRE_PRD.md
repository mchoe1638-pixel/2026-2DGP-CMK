# PRE_PRD — 소닉 애니메이션 뷰어 요구사항 초안

> 구현 방법보다 **필요한 동작**을 먼저 적은 초안이다.
> 세부 규칙(프레임 좌표, 이동 방식, 완료 기준)은 이 초안을 바탕으로 `PRD.md`에서 정한다.

## 꼭 필요한 기능

| 항목 | 조건 |
|------|------|
| 도구와 파일 | Python, pico2d, 단일 `sonic_animation_viewer.py`, `sonic-sprite.png` |
| 재생 | 이미지의 모든 동작을 원본 크기의 4배로 표시 |
| 전환 | 동작별 5회 반복, 1초 정지, 다음 동작으로 전환 |
| 전체 순환 | 마지막 동작 뒤 첫 동작부터 다시 재생 |
| 개발 과정 | 단계별 구현과 커밋을 반복해 최소 20회 커밋 |

## 아직 정하지 않은 것

- 어떤 동작이 화면에서 이동하는지
- 프레임을 어떻게 자르는지 (시트의 프레임 좌표)
- 정지 중 어떤 화면을 유지하는지
